# Balance Game 프로젝트 최종 보고서

## 📋 프로젝트 개요

### 프로젝트명
**Balance Game** - 밸런스 게임 플랫폼

### 프로젝트 설명
다양한 주제의 밸런스 게임 질문을 제공하고, 사용자가 원하는 질문을 조합하여 자신만의 질문 묶음을 만들고 공유할 수 있는 웹 서비스입니다. 개인 중심의 게임 플레이와 8자리 공유코드를 통한 결과 비교 기능을 핵심으로 합니다.

### 개발 기간
2024년 개발 → **2025년 1월 Azure 배포 완료**

### 🌐 **실제 서비스 운영 중**
- **서비스 URL**: https://balance-game-ekedbfhkcxeyc8cb.koreacentral-01.azurewebsites.net
- **상태**: 정상 운영 중 ✅
- **배포 환경**: Microsoft Azure Cloud Platform

### 개발 환경 및 배포 스택
- **백엔드**: Spring Boot 3.2.6, Java 17
- **데이터베이스**: Azure Database for PostgreSQL (Flexible Server)
- **프론트엔드**: React.js (Next.js)
- **클라우드**: Microsoft Azure
  - App Service (Linux B1)
  - PostgreSQL (Standard_B1ms)
  - Blob Storage
- **빌드 도구**: Gradle
- **배포**: Azure CLI + PowerShell 자동화

## 🎯 핵심 기능

### 1. 사용자 권한 체계
```
비회원 → 일반회원 → 관리자 (3단계 권한 구분)
```

#### 비회원 기능
- ✅ 질문/묶음 탐색 및 검색
- ✅ **개인별** 밸런스 게임 플레이
- ✅ **8자리 공유코드** 생성 및 공유
- ✅ **결과 비교** 및 일치율 계산

#### 일반 회원 기능
- ✅ 질문 묶음 생성/편집/삭제
- ✅ **질문 요청** (승인제)
- ✅ 묶음 복제(Clone)
- ✅ 마이페이지 (게임 기록, 요청 상태 등)

#### 관리자 전용 기능
- ✅ **질문 승인 관리** (요청 검토/승인/거절)
- ✅ **콘텐츠 품질 관리** (중복 탐지, 부적절 콘텐츠 차단)
- ✅ **시스템 관리** (사용자 관리, 통계 모니터링)

### 2. 게임 플레이 시스템

#### 플레이 플로우
1. **개인이 혼자** 질문 묶음 플레이
2. 완료 후 **8자리 공유코드** 자동 생성
3. 친구가 공유코드로 같은 질문 플레이
4. **일치율 자동 계산** 및 문항별 비교 표시

#### 주요 특징
- **개인 중심 플레이**: 기존 멀티플레이어 방식에서 개인 플레이로 변경
- **공유코드 시스템**: 8자리 고유 코드를 통한 결과 공유
- **비교 분석**: 문항별 선택 결과 및 전체 일치율 제공

### 3. 질문 승인 시스템

#### 승인 플로우
1. 사용자가 질문 생성/수정/삭제 **요청**
2. **승인 대기** 상태로 저장 (`PENDING`)
3. 관리자가 검토 후 **승인/거절**
4. 승인시 서비스 반영, 거절시 사유 안내

#### 품질 관리
- **모든 질문** 관리자 검토 필수
- **일괄 승인** 기능으로 효율적 관리
- **거절 사유** 제공으로 개선 유도


#### JWT 토큰 구조
- **Access Token**: 1시간 유효기간 (3600초)
- **Refresh Token**: 7일 유효기간 (604800초)
- **HttpOnly Cookie**: XSS 방지
- **Secure Cookie**: HTTPS 전용

#### OAuth2 소셜 로그인
- **Google OAuth2**: 구글 계정 연동 ✅
- **Kakao OAuth2**: 카카오 계정 연동 ✅
- **자동 회원가입**: 첫 로그인 시 자동 계정 생성

#### 보안 강화 사항 (2025년 1월 개선)
```java
// CORS 보안 강화
configuration.setAllowedHeaders(Arrays.asList(
    "Content-Type", "Authorization", "X-Requested-With", "Cache-Control"
)); // 기존 "*" 에서 특정 헤더만 허용

// JWT Refresh Token 추가
public TokenDto createTokenDto(Authentication authentication) {
    String accessToken = createToken(authentication);
    String refreshToken = createRefreshToken(authentication);
    return TokenDto.of(accessToken, refreshToken, accessTokenExpirationTime / 1000);
}
```

#### N+1 쿼리 문제 해결
```java
// 기존 코드 (N+1 문제 발생)
List<UserAnswer> findByGameSessionId(Long sessionId);

// 개선된 코드 (Fetch Join 적용)
@Query("SELECT ua FROM UserAnswer ua JOIN FETCH ua.question WHERE ua.gameSession.id = :sessionId ORDER BY ua.question.id")
List<UserAnswer> findByGameSessionId(@Param("sessionId") Long sessionId);
```

#### 공유코드 생성 알고리즘 개선
```java
// 기존: 완전 랜덤 (충돌 위험)
// 개선: 타임스탬프 기반 + 랜덤 (충돌 최소화)
public String generateShareCode() {
    long timestamp = System.currentTimeMillis();
    String timePrefix = Long.toString(timestamp % 46656, 36).toUpperCase();
    String randomSuffix = generateRandomString(8 - timePrefix.length());
    return timePrefix + randomSuffix;
}
```
